# DO_CICD
Ветка по изучению основ DevOps
- Задание 1-4: изучение Linux, сетевого администрирования (не включены в репозиториий)
- Задание 5: Введение в докер. Разработка простого докер-образа для собственного сервера
- Задание 6: Разработка простого CI/CD для проекта на Си. Сборка, тестирование, развертывание

## DO5_SimpleDocker
Практика по Docker: работа с готовыми контейнерами, написание Dockerfile, docker-compose, проверка безопасности через dockle. Написан мини-сервер на C + FastCGI, проксируется через nginx внутри контейнера. Сборка образа с nginx, монтаж конфигурации, compose-проект из двух контейнеров.

Стек: Docker, Docker Compose, nginx, FastCGI, C, dockle.

## DO6_CICD
Практика по CI/CD: настройка gitlab-runner, написание пайплайна в .gitlab-ci.yml. Этапы: сборка, clang-format, интеграционные тесты, деплой по SSH на вторую виртуальную машину, автоматизация уведомлений в Telegram.

Стек: GitLab CI, gitlab-runner, Ubuntu Server, SSH/SCP, bash.
